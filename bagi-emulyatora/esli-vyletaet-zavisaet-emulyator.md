***!!ПРОВЕРЬТЕ, ЧТО У ВАС ТОЧНО ВЕРСИЯ Canary!!***

( часто, если версия не canary, выходит ошибка "`System.ArgumentOutOfRangeException: Specified argument was out of the range of valid values`" )

[Подробнее про версию эмулятора](./../momenty-ustanovki/pravilnaya-versiya-emulyatora.md)

## Удостоверьтесь, что:

* [ ] \- вы вытащили папку publish из сжатого архива, который вы скачали, папка обязательно должна быть извлечена, например, на рабочий стол;

* [ ] \- вы не вытаскивали приложение Ryujinx из папки publish, это приложение должно всегда находиться в этой папке, т.к. в ней находятся все необходимые библиотеки, к которым обращается Ryujinx (иначе в консоли может показываться ошибка типа “`Avalonia.Skia … Dll was not found`”;

* [ ] \- в настройках эмулятора в Game Directories правильно указана папка, в которой находится файл игры весом 6 ГБ;

* [ ] \- в Game Directories или Updates Directories не указаны несколько папок, лишние удалите с помощью кнопки Remove;

* [ ] \- папка для Autoload DLC/Updates Directories не находится в папке, которая указана в Game Directories. Эти папки не должны находиться друг в друге:

* [ ] \- папка, указанная в Game Directories/Updates Directories не находится в папке загрузок другого приложения, например телеграма “Telegram Desktop”.

## Если у вас по пунктам выше всё в порядке, попробуйте:

* [ ] \- отключить защиту Windows Defender (если не знаете как – гуглим);

* [ ] \- скачать Visual C++ Redistributable через официальный сайт Microsoft и перезагрузить ПК/ноут (иногда помогает при ошибке "`Avalonia.Skia … Dll was not found`");

* [ ] \- установить более новую/старую версию эмулятора;

* [ ] \- добавить файл подкачки (!часто помогает при ошибке "`инструкция по адресу ... обратилась к памяти по адресу ... Память не может быть read`") ; инструкция: откройте приложение Система, затем во вкладке О Системе нажмите на “Дополнительные параметры системы”, в открывшемся окне во вкладке Дополнительно в пункте Быстродействие (Визуальные эффекты…) нажмите на Параметры. В Параметрах быстродействия нажмите во вкладке Дополнительно нажмите кнопку Изменить, затем уберите галочку возле “Автоматически выбирать объём файла подкачки”. Потом нажмите на “Указать размер”, в Исходный размер впишите число, которое написано напротив “Рекомендуется”, в Максимальный размер впишите число, которое написано напротив “Текущий размер”. В конце нажмите ОК и перезагрузите ПК/ноут.
