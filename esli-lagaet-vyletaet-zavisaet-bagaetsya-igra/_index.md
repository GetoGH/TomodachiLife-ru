## В настойках эмулятора:

Жмите Options, потом Settings

#### во вкладке Graphics:

* [ ] \- менять Graphics Backend на opengl/vulkan (opengl для менее производительных ПК обычно)

* [ ] \- Graphics Backend Multithreading включить или выключить

* [ ] \- Enable Texture Recompression включить или выключить ( сжатые текстуры, снижение)

* [ ] \- Enable Macro HLE включить или выключить

* [ ] \- Anisotropic Filtering поставить 2x/4x ( улучшение графики)

#### во вкладке CPU:

* [ ] \- Low-Power PPTC включить или выключить

* [ ] \- Memory Manager Mode поставить Host (fast)

* [ ] \- На крайняк в Turbo Mode Multiplier изменить на 60-100

#### во вкладке System:

* [ ] \- Vsync поставить Switch

* [ ] \- Ignore Missing Services включить (при вылетах типа “ставлю часы на карте и все ломается”)

#### во вкладке Audio:

* [ ] \- Audio Backend меняйте на другие

## Параметры ОС

Откройте приложение Параметры -> Система -> Дисплей -> Графика (параметры графики) -> Добавьте классическое приложение -> найдите папку publish, там выберите приложение Ryujinx, Ryujinx должен появиться в списке, жмите на него -> Параметры GPU поставьте "Высокопроизводительный..."

## Моды

Удалите все моды/русификаторы и иные добавки для игры, если скачивали их (может помочь при ошибке в консоли “`Invalid memory access at virtual address…`”

## Закройте все фоновые приложения

Закрыть все процессы в диспетчере задач (если не знаете как – гуглим) ; однако эмулятор может слететь, скачивайте снова, если не открывается
